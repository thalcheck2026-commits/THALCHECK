CBC values

How to read the ranges. Each index has a cutoff. A value in the thal trait range favours beta-thalassemia trait; a value in the IDA range favours iron deficiency anemia. Typical thal trait: low MCV and MCH with a normal or raised RBC and a normal RDW. Typical IDA: low MCV and MCH with a low RBC and a raised RDW. Reference ranges above are adult values and vary by lab, so use your own lab's ranges if they differ.

Custom logistic model

This model is built into the app and applies to every user automatically. It cannot be edited here. To change it, the app owner edits the file.

Enter the coefficients for the model that predicts thalassemia trait. logit = intercept + b·HCT + b·MCV + b·MCH + b·RDW. Leave blank to skip the model.

Where data lives

Shared storage makes every record visible to all users of this app. Use sample IDs only, never patient names or contact details. Switching mode changes which set of records you see; it does not move them.
